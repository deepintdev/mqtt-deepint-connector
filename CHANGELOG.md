# Changelog

## 1.1 - 2026-10-28

- The test script reads the broker, MQTT credentials and AIR-Core token from the environment instead of having them in the repository.
- Document how to choose the AIR-Core instance (`AIRCORE_INSTANCE` / `DEEPINT_INSTANCE`, deepint SDK 1.5 or later).
- Rebranded documentation, CLI help, log messages and the systemd unit description from Deep Intelligence to AIR-Core (formerly Deep Intelligence).
- The project link now points to https://app.air-core.io.
- No changes to the command name, package name, CLI arguments or the `deepint` SDK dependency.
